
# Loan Approval Prediction using Machine Learning

## Project Overview
This is a Machine Learning project that predicts loan approval status using a Decision Tree Classifier.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Google Colab

## Machine Learning Model
Decision Tree Classifier

## Accuracy
80%

## Result
The model successfully predicted the loan status of a sample test record as Approved.

## Learning
Through this project, I learned data preprocessing, train-test splitting, model training, evaluation, and prediction.
